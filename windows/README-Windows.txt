Click Meow · 点一下，喵一下 — Windows 便携预览版

适用：Windows 10 / 11，64 位 x64。

1. 解压整个 ZIP 到你想长期保留的文件夹。
2. 双击 click-meow.exe。不要只把 exe 单独拖出来，也不要直接在压缩包内运行。
3. 点击其他窗口中的鼠标左键，应该听到随机猫叫。
4. 在右下角托盘中找到猫咪图标（可能位于折叠菜单），点击打开设置；右键可暂停或退出。

初始音量 30%。关闭设置窗口后仍在托盘运行；再次启动 exe 会打开已有实例的设置。
“登录桌面时自动启动”默认关闭，启用后写入当前用户的 Windows 启动项，不需管理员权限。
移动程序文件夹后，请取消并重新勾选自启动。删除程序前也请先关闭自启动并退出。
“添加自己的猫叫”可打开用户音源目录；支持单个不超过 10 MiB 的 PCM WAV 文件。

请在你的电脑验证：
- 试听、在资源管理器/浏览器等其他窗口点击、快速双击。
- 右键/滚轮/按住左键拖动时不额外猫叫。
- 暂停和恢复、音量保存、退出后不再播放。
- 鼠标和触摸板（如果有）、锁屏后解锁、自启动。

这是首次 Windows 预览版。自动构建检查不等于已经完成真实电脑上的声音和输入测试。
便携指无需安装；设置与自定义音源仍保存在当前用户的配置/数据目录。

源码与问题反馈：https://github.com/ellery444/click-meow
Windows 输入使用 Raw Input，不拦截正常点击，也不监听键盘。
